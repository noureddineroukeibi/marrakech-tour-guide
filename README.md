# Marrakech & Agafay Tour Guide

A responsive web guide showcasing experiences across **Marrakech** and the **Agafay Desert**, including desert activities, a photo gallery, and direct booking options.

## Features

- **Responsive design:** Adapts to mobile, tablet, and desktop screens.
- **Marrakech and Agafay tours:** Highlights local culture and desert experiences.
- **Photo gallery:** Showcases Agafay landscapes and camel rides.
- **Direct booking:** Contact the guide through WhatsApp.

## Built With

- HTML5
- CSS3

## Deployment

- Source code hosted on **GitHub**.
- Live deployment managed via **Vercel**.
